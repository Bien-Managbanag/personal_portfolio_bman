# Personal Portfolio | Bien Managbanag

A personal portfolio website built using **React, JavaScript, CSS, and Vite**, designed to showcase my background, technical skills, software development projects, and journey as a Computer Applications and Software Engineering graduate from Dublin City University.

The website features a **comic-book-inspired design**, drawing inspiration from superhero comics through bold typography, vibrant colours, illustrated-style panels, and interactive elements.

### 🌐 Live Website

**[View My Portfolio](https://bien-managbanag.github.io/personal_portfolio_bman/)**

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| React | Building reusable components and interactive pages |
| JavaScript | Application functionality and interactivity |
| HTML & CSS | Website structure, styling, and responsive layouts |
| Vite | Development environment and production builds |
| React Router | Navigation between portfolio pages |
| Git & GitHub | Version control and source code management |
| GitHub Pages | Website hosting |
| GitHub Actions | Automated building and deployment |

## ✨ Features

- **Comic-book-inspired interface:** Custom styling featuring bold colours, typography, borders, and panel layouts.
- **Multi-page navigation:** React Router enables navigation between sections without full page reloads.
- **Interactive origin story:** Expandable panels detailing my background, university education, Erasmus experience, and graduation.
- **Technical skills showcase:** Highlights programming languages, frameworks, development tools, and technologies.
- **Project portfolio:** Displays software development projects with descriptions, screenshots, and technology tags.
- **Responsive design:** Layouts designed to adapt to different screen sizes.
- **Automated deployment:** GitHub Actions builds and deploys the website when changes are pushed to the main branch.

### Projects

Features a selection of academic and personal software development projects.

**1. DCU Expo Application**

A mobile application developed as part of a two-person final-year project to replace the printed DCU Project Expo booklet. Built using Ionic and Angular, with a C# backend, SQL Server database, and AWS infrastructure.

**Technologies:** Ionic, Angular, TypeScript, C#, SQL Server, AWS, REST APIs.

**2. Restaurant POS System**

A Java-based command-line point-of-sale application that simulates restaurant ordering, including menu navigation, adding and removing items, input validation, and automatic total calculations.

**Technologies:** Java, Object-Oriented Programming, CLI.

**3. Python Web Scraper**

A web scraping application using Scrapy to extract structured product information from a demonstration e-commerce website. Integrates MongoDB for data storage and includes three automated tests.

**Technologies:** Python, Scrapy, MongoDB, Unit Testing.
